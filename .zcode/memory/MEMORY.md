## 项目基本面

- 游戏：锻刀大师（英文名待定，暂用 Forge Master，商用前商标查询）——超写实锻造模拟 + 竞技比赛（类锻刀大赛赛制，表达全原创）+ 轻度模拟经营；Godot 4 3D；PC（Steam）
- 核心设计：三层架构（sim 模拟层 / 感知层 / 表现层）；"刀剑即数据"（BladeData = 16 段截面控制点）；隐藏属性系统（内应力/晶粒度等锻造中积累、测试时爆发）——拟真活在数值里，画面走轻量风格化
- 美术定位（用户拍板 2026-10-14）：**"超写实"指玩法模拟深度，不是美术写实**；全场 2 个内景、人物用 2D 立绘、刀剑是唯一高规格渲染对象、预算押特效四件套（炉火/火花/蒸汽/断刀慢镜）
