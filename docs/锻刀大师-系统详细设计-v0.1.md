## 0. 设计总纲：拟真在数据里，简单在画面上

全项目遵守一条铁律：**"超写实"是模拟层的追求，不是渲染层的追求**。美术走轻量风格化，所有真实感由三件事承担：

1. **数值模拟真实**——温度、形变、金相遵循简化但自洽的真实物理模型；
2. **前兆信号可读**——每个隐藏问题都有火色/声音/手感上的预警，玩家能学会"读钢"；
3. **表现层集中在少数高回报特效**——炉火、火花、蒸汽、断刀慢镜头，其余画面从简。

### 三层架构

```
┌─────────────────────────────────────────────────┐
│ 表现层  场景/网格/粒子/音效/UI —— 只读模拟状态      │  Godot 场景树
├─────────────────────────────────────────────────┤
│ 感知层  把模拟数值翻译成玩家可读信号（火色/音色/震感）│  少量胶水代码
├─────────────────────────────────────────────────┤
│ 模拟层  SimCore：纯 GDScript、无节点依赖、可单测    │  res://sim/
│         刀坯数据 / 热传导 / 锻打 / 热处理 / 评分     │
└─────────────────────────────────────────────────┘
```

- 模拟层与表现层**完全解耦**：SimCore 不知道 Godot 场景树的存在，用固定步长（10 Hz）推进；这样可单元测试、可做 AI 快速生成武器、可序列化分享。
- 表现层只做两件事：把 `BladeData` 渲染成网格；订阅模拟事件（击打、淬火、断裂）播放特效音效。

## 1. 数据模型：刀剑即数据（一切的地基）

### 1.1 刀坯 BladeData

刀坯 = 沿刃脊线排列的 N 段截面（初版 N=16，动力锤时代可升 24）。

```gdscript
class SectionData:          # 一段刀坯（模拟层纯数据）
    var x: float            # 沿刃脊的弧长位置 (mm)
    var width: float        # 截面宽 (mm)
    var thickness: float    # 截面厚 (mm)
    var offset_y: float     # 侧向偏移（弯扭矫正量，mm）
    var bevel: float        # 开刃角预留 (°)
    # ---- 模拟状态 ----
    var temp: float         # 温度 (°C)
    var stress: float       # 内应力 0~100
    var grain: float        # 晶粒尺寸 1~10（1 细密 10 粗大）
    var carbon: float       # 碳含量 %（玉钢/废料时逐段不同）
    var hardness: float     # 洛氏硬度 HRC（淬火回火后写入）
    var soak: float         # 奥氏体化充分度 0~1
    var hairline: bool      # 发丝裂纹标记（淬火判定）
    var burned: bool        # 研磨过热退火标记

class BladeData:
    var steel_id: String            # 钢材 id → SteelDef
    var sections: Array[SectionData]
    var crack_severe: bool          # 淬火当场断裂
    var heat_ops: Array             # 热处理履历（正火几次/回火参数）
    var tang: TangData              # 龙骨配置
    var handle: HandleData          # 柄装配置
```

### 1.2 成品 WeaponData

```gdscript
class WeaponData:            # 成品 = 刀坯 + 派生六维 + 外观信息
    var blade: BladeData
    # 派生属性（由 score.gd 从 BladeData 计算，玩家不可见）
    var edge_retention: float    # 刃口保持 0~100
    var toughness: float         # 韧性 0~100
    var strength: float          # 结构强度 0~100（含装柄）
    var sharpness: float         # 锋利度 0~100
    var geometry: float          # 形制还原 0~100
    var cosmetic: float          # 外观分 0~100
    var mass_g: float            # 总重 (g)
    var pob_mm: float            # 配重中心距护手距离 (mm)
```

### 1.3 数据模型的回报

- **存档/分享**：`WeaponData` 序列化为 Resource 或 JSON → base64 分享码，未来异步对战直接传码；
- **AI 对手**：按规则生成一份 `WeaponData` 即参赛，无需模拟 AI 实时打铁；
- **评分/测试**：全部围绕六维计算，公式统一；
- **网格生成**：表现层由 sections 重建网格（见 §12）。

## 2. 温度系统（拟真的第一支柱）

### 2.1 模型：简化一维热传导

每段独立温度，10 Hz 定步长推进（dt=0.1s）：

```
T_i(t+dt) = T_i
    + α · (T_{i-1} + T_{i+1} − 2·T_i)          # 邻段传导（傅里叶简化）
    − β_i · (T_i − T_amb)^{1.15}               # 空气冷却（牛顿冷却加辐射修正）
    + Q_i                                       # 炉内加热（在炉段才有）
```

- `α`：钢材导温系数（游戏标定值，各钢一致即可）；
- `β_i`：散热系数——**端部（刀尖/龙骨端）散热比中段快 1.6 倍**（真实规律：端面/边角散热快，所以打刀要抢端部温度）；细薄段热容小、升温快降温也快（`V_i = w·th·Δx` 参与归一化）；
- `Q_i`：炉子功率 × 该段被炉膛覆盖比例 × 炉型效率。煤炉功率波动 ±15%（拟真控温难点），燃气炉 ±3%，感应炉可设定恒温。

### 2.2 温度-颜色对照（火色表，感知层核心）

自发光颜色由黑体辐射近似查表（shader 里一张 256×1 渐变纹理）：

| 温度 | 火色 | 游戏含义 |
|---|---|---|
| ≤480°C | 黑（不可见） | 冷钢 |
| 550°C | 隐约暗红 | 预热中 |
| 650~700°C | 暗红 | **停锻线**：再打只积累应力 |
| 700~850°C | 樱桃红→亮红 | 收尾精锻、矫直区间 |
| 850~1050°C | 橙→亮橙 | **主力锻造区间** |
| 1050~1150°C | 橙黄→黄 | 拔长重锻、锻焊 |
| 1150~1250°C | 亮黄→黄白 | 危险：晶粒快速粗化 |
| >1250°C | 白亮飞溅火花 | **过烧**：钢材开始脱碳熔损，几秒判废 |

> 注：此表取代策划案 v0.1 §3.3 的简化表（v0.1 把锻造区间写低了，真实刀钢主力锻造在橙区 850~1050°C）。

辅助档位：辅助模式叠加数字温度；拟真模式只有火色 + 可购买红外测温仪（器械升级解锁）。

### 2.3 磁性测试（免费又拟真的临界温度判断）

碳钢居里点 ≈ 770°C。淬火前把磁铁贴到刀坯上：**吸不住 = 已过临界温度可以淬**；配合火色双重确认。实现：一个道具挂点 + 吸附/脱落两态动画，读 `T_i > 770`。

## 3. 锻打系统（操作核心）

### 3.1 输入解析

鼠标点击 → 射线与刀坯包围盒求交 → 投影到刃脊曲线 → 得到段号 `i` 与命中法线（上面/左面/右面）。
- 打**上面**：压厚度 → 宽度外扩（拔长/展宽的主操作）；
- 打**侧面**：改 `offset_y`（矫直弯扭）。

### 3.2 形变公式（体积守恒）

```
m_i = clamp((T_i − 700) / 200, 0, 1)          # 可锻性：700°C 以下为 0，900°C 以上为 1

打上面:
Δth_i = −K · P · m_i                           # P=锤力档位(0.4/1.0/2.2) K=标定系数
Δw_i  = −Δth_i · (w_i / th_i) · 0.88          # 体积守恒，12% 损耗为氧化皮飞溅
邻居衰减: Δ(x) = Δ · 0.35^|i−x|               # 高斯式扩散，保证曲面光滑
```

结果约束：`thickness ≥ 1.5mm`（打太薄直接软塌报警），`width ≤ 砧面宽 +30%`。

### 3.3 应力与晶粒（隐藏属性的积累）

```
每次锤击:
stress_i += S0 · P · ( (1−m_i)·1.0 + 0.15 )    # 冷打应力大，热打也有少量
若 T_i > 1150°C 持续:
grain_i += G0 · (T_i − 1150)/100 · dt          # 过热粗化，不可逆（只能正火部分挽救）
```

- 冷打（T<700）：几乎不变形但应力暴涨——玩家自然学会"抢温打"；
- 过热打（T>1150）：变形效率极高（陷阱！），晶粒悄悄粗化，测试环节脆断——**短期爽、长期死的经典抉择**。

### 3.4 锤型参数表

| 锤 | P 力 | 适用 | 特性 |
|---|---|---|---|
| 手锤 | 0.4 | 精修、矫直 | 应力系数 ×0.5，变形小 |
| 锻锤 | 1.0 | 常规锻造 | 标准值 |
| 动力锤 | 2.2 | 大刀坯拔长 | 可设锤击程序（沿刃脊扫一遍），单锤应力 ×1.2，噪声大 |

### 3.5 矫直小玩法

`offset_y` 超差的刀在砧上进入矫直视角：视线沿刃脊看过去（真实铁匠检查法），点击凸起处轻敲修正。省去数值界面，又教了真手艺。

### 3.6 形制评分

赛题/订单给目标截面曲线（`target[]`），评分 = `100 − k·Σ|current − target|`，锻造时半透明叠影显示目标轮廓，偏差实时可见。

## 4. 热处理系统（拟真成败的关键，最"深"的系统）

### 4.1 钢材定义表（真实参数标定进游戏）

| 钢材 | C% | 临界淬温 | 淬透性 | 淬后HRC上限 | 韧性基 | 淬裂敏感 |
|---|---|---|---|---|---|---|
| 1045 | 0.45 | 830±20 | 差（需水/盐水） | 56 | 高 | 低 |
| 1084 | 0.84 | 800±15 | 中（油可） | 61 | 中 | 中 |
| 1095 | 0.95 | 785±15 | 中 | 64 | 中低 | **高** |
| 5160 | 0.60 | 815±15 | 好（油轻松） | 58 | **极高** | 低 |
| W2 | 1.05 | 780±15 | 差（水淬传统） | 65 | 低 | **极高**（但可做刃纹） |
| 15N20+1095 | 复合 | — | — | 62 | 中 | 中（看锻焊质量） |
| 玉钢 | 逐段0.3~1.5 | 逐段判定 | 差 | 58~64 | 看折叠 | 高 |

（表存 `data/steels/*.tres`，数值以真实手册为参照、以可玩性微调，标定过程写注释。）

### 4.2 正火 / 退火

- **正火**：加热到 850°C 左右 → 取出空冷至黑，可执行最多 3 次，每次：`grain_i = lerp(grain_i, 1.0, 0.45)`、`stress_i ×= 0.55`。真实作用（细化晶粒、消除应力）直接映射成数值。
- **退火**：随炉慢冷一夜（时间跳过），效果：研磨效率 ×1.4，并再降一次应力。做成可选工序——跳过省时间，但后段研磨费工时。

### 4.3 淬火（演出高潮 + 最大风险点）

**流程**：加热 → 磁铁确认失磁（>770°C）→ 升至该钢临界淬温窗口 `[Ac_下限, Ac_上限+40]` → **保温**（奥氏体化）→ 选介质入液。

**① 奥氏体化充分度（保温计时）**：

```
需要时间 τ = 0.8 + thickness_i/10   (游戏秒，厚截面要烧透)
soak_i = clamp(在温时间/τ, 0, 1)     # 没烧透=淬不硬，soak 直接乘进硬度
```

**② 冷却速率判定（Grossmann H 值简化）**：

```
介质烈度 H: 静止油 0.25 / 循环油 0.4 / 水 1.0 / 盐水 1.8
各段冷速 r_i = H · C / thickness_i          # 薄段冷得快（真实规律）
该钢临界冷速 r_c（1045/W2 很高，5160 很低）
淬硬程度 h_i = clamp(r_i / r_c, 0, 1)
hardness_i = HRC_max · h_i · soak_i
```

一次淬火，水和油的差别、厚薄刃的差别全部自然涌现——**不需要专门写"水淬容易裂"的特例，模型自己长出来**。

**③ 淬裂判定（两级裂纹，本作最得意的拟真演出）**：

```
p_crack = clamp0_1(
      0.30·(grain_avg/10)            # 晶粒粗化
    + 0.25·厚度不均度(各段th的CV值)   # 截面突变=应力集中
    + 0.20·淬火瞬间全刀温差/300       # 局部过热就淬
    + 0.20·(H−0.4)·碳敏感系数         # 高碳钢+水=经典翻车
    + 0.10·(1−已正火次数/3)·0.5
    − 0.15·回火预定加成(无)
)
掷签:
  p×0.35 概率 → 严重裂纹：入液瞬间"咔"——延迟 1.5 秒再响（真实：裂纹发生在冷透过程中）
  p×0.65 概率 → 发丝纹 hairline=true：当场无声无息，研磨到 400 目时"发现一条发丝纹"，
               或直接带到强度测试，弯折时沿纹崩开
```

发丝纹设计是**悬念工具**：测试台前你永远不知道自己那刀有没有暗伤。

**④ 介质演出**：蒸汽/油烟粒子量 ∝ ΣT_i·V_i；油面火苗（油温过高时）点光源闪烁 + 提示（老油新油参数差异留作后期）。

### 4.4 回火

淬火后必须回火（未回火=玻璃刀，一敲即碎，教学关演示一次）：

```
参数: θ (150~400°C) × 时长 (1~4h，烘箱里时间快进)
硬度: HRC_final = HRC_quench · f(θ)     # 150→1.00 200→0.97 250→0.90 300→0.82 350→0.72 400→0.62
韧性: toughness ∝ (1−f(θ)) 的曲线 + 钢种基值
应力: stress ×= 0.35（回火不足/温度太低则只 ×0.7，残留应力）
```

**回火色（拟真反馈）**：低温氧化在刃口显色带——220°C 淡麦黄 / 245 金黄 / 265 棕紫 / 280 紫 / 300 蓝。老玩家看刃口颜色就知道回火到位没，这是真实工艺里铁匠的"仪表盘"。shader 用一张温度→颜色 LUT 贴在刃缘条带上。

## 5. 研磨与开刃

### 5.1 磨削模型（磨掉的材料真的消失）

```
按住推进 → 各段:
  bevel_i → 目标角度（玩家控制角度摇杆，超出±3° 报警刮削声）
  width_i −= 磨削量（体积不守恒——磨掉的铁变成火花/铁屑，真实！）
  表面粗糙度: 砂目档位 80→240→400→800→2000 逐级刷新 surface_rough
  研磨热: temp_i += 磨削功率·dt / V_i（薄刃升温快）
    若 temp_i > 200°C: burned_i = true（刃口局部退火+蓝色氧化斑）——水冷砂带机器械可免疫
```

### 5.2 锋利度合成

```
sharpness = clamp( k1·(grit/2000) + k2·(1 − |edge_angle−20°|/35°) + k3·hardness均匀度 )
edge_retention = clamp( k4·avg(hardness) + k5·钢种耐磨基值 − 细裂纹罚分 )
```

荡刀石工位做最终开锋：一个简短的往复拖拽动作，把 sharpness 顶到上限。

## 6. 装柄与整刀物理

### 6.1 结构强度

```
龙骨类型: 通龙骨(1.0) / 棒式插入(0.75) / 尾铆(0.6)
装柄质量: 胶覆盖率·0.6 + 销钉数/4·0.4（钻孔对位 minigame 影响覆盖率）
handle_strength = 龙骨系数 × 装柄质量 × (1 − 0.3·pob失衡度)
```

装柄失败演出：强度测试打到一半**手柄横飞**、光杆刀插在靶子上（全场哗然）——低成本高戏剧性。

### 6.2 配重（真实刀剑衡量指标）

```
m_i = 7.85 g/cm³ × w_i·th_i·Δx      （钢材密度）
整刀质心 PoB = Σ(m_i·x_i + 柄件质量矩) / Σm，报告为"距护手 X 指"
理想区间按武器类型: 菜刀 +0~1 指 / 猎刀 +1~2 / 长剑 +2~4
PoB 越靠前劈砍越狠但挥动越慢（实战测试的挥速参数直接引用此值）
```

## 7. 成品评价与武器测试

### 7.1 六维派生（score.gd，纯函数）

```
toughness  = 钢种韧性基 · f(回火) · (1 − stress/150) · (1 − grain/20) · (1 − hairline×0.6)
strength   = min(刃部toughness, handle_strength) · 几何均匀度
edge_ret./ sharpness / geometry / cosmetic 见 §5 §3.6 §9
```

### 7.2 三大测试（状态机 + 预制物理，不做实时切割）

每个测试 = 一段脚本化运镜 + 若干物理事件：

| 测试 | 脚本 | 判定 |
|---|---|---|
| **强度测试** | 砍硬物 3 次（按武器类型选：钢桶/冰砖/骨排），再压弯 15° | 每次撞击对刀施加虚拟应变 ε，`ε > toughness阈值` → 崩刃；压弯看 `stress`：回弹/永久弯/断 三结局，慢镜头 |
| **锋利测试** | 连斩绳捆/竹席/水瓶阵（预切关节件） | `切深 = sharpness·挥速·质量集中度 vs 材料阻力`，刃口每次硬接触掷 `edge_retention` 衰减 |
| **实战测试** | 凌霜连招劈刺弹道假人（预切件+关节） | 综合三项 + PoB 影响挥速表现，收尾判定词 |

断裂表现：命中判定瞬间 `Engine.time_scale = 0.25` + 切换预制断刀模型 + 碎片刚体抛散 + 相机震动。所有"切割感"来自**预切块的关节破坏**，永不运行时切网格。

### 7.3 测试后的归因

测试失败时评委逐条点评真实原因："淬火温差过大""回火不足听声就脆"——把隐藏数值翻译成教学信息，构成学习循环。

## 8. 竞技比赛系统

### 8.1 比赛状态机

```
Briefing 出题(限定参数/材料) → Round1 锻造(60~90 游戏分钟, 模拟层时间×60快进)
→ R1评审(工艺+几何, 淘汰1) → Round2 装柄精修(30~45分钟)
→ 两项测试(强度+锋利) → 淘汰1 → Round3 决赛命题(回家锻造=高预算自由时段+天数跳过)
→ 三测定冠 → Ceremony(奖金/名声/解锁)
```

比赛与自由模式共用同一套工位场景，仅参数与计时不同。

### 8.2 AI 对手武器生成器（数据驱动，零实时模拟）

```gdscript
func gen_rival_weapon(profile: RivalProfile) -> WeaponData:
    # profile: 难度0~1 + 原型(稳健老匠/激进新人/学院派/野路子)
    按 profile.skill 生成 sections（均值好、方差小）
    六维 = 基线(钢种) × profile.skill × 原型偏置
    按 (1 − skill)·原型缺陷倾向 注入 0~2 个缺陷:
        冷叠层 / 软点 / 发丝纹 / 热处理欠火 / 配重失衡 / 形制走样
    缺陷在测试环节按真实规则爆发（AI 也会翻车，节目名场面）
```

评委打分：`总分 = 0.35·工艺 + 0.25·几何形制 + 0.30·测试 + 0.10·外观`，三位评委各自权重偏置不同（沈重工艺、顾重形制、凌重测试）→ 玩家可按评委口味扬长避短。

### 8.3 随机组队与赛季

- 对手池 ≥20 份档案，报名时**种子随机抽 3 人**组队（种子 = 存档 UID + 届数，可复现可分享"我这一届遇到了谁"）；
- 段位积分、赛季轮换命题池；分享码 = `base64(var_to_bytes(WeaponData))` + CRC，本地先跑通，异步云端评比后置。

### 9.1 定价模型

```
售价 = (材料成本 + 工时×费率) × 品质系数(0.5~2.5, 由六维加权) × 订单加成(1.0~1.5)

大赛奖金: 冠军 3000~8000 + 声望, 越高段位越多
```

### 9.2 器械升级 = 解锁模拟层的便利（不替代手艺）

## 11. 美术方案（简洁实现的风格化）

- **总风格**：风格化写实-lite——低多边形场景 + `StandardMaterial3D` 平涂/简单贴图，暖色炉火主导照明（一盏主点光+微弱冷色补光），不追求 PBR 精度。参考气质：暖光工坊 + 深色背景 + 高饱和火光。
- **场景清单（全场仅 2 个内景）**：①铁匠铺工坊（8 工位，经营升级改装饰件）；②大赛校场（测试台+观众剪影+评委席）。模块化家具复用。
- **刀剑渲染**：程序生成网格，无贴图——金属色 + 逐顶点 emissive（温度）+ 刃口色带（回火色）+ 后期镜面（砂目决定 smoothness）。**刀是主角，它值得唯一的高规格渲染**。
- **人物**：不建模 3D 角色。评委/AI 对手/顾客全部用 **2D 立绘头像 + 档案卡 + 字幕对话**（比赛演出 = 运镜 + 立绘 + 音效），成本砍 80%，还带综艺感。
- **特效四件套**（美术预算全押这里）：炉火（粒子+光晕+音）、锤击火花（方向性 burst）、淬火蒸汽/油烟（体积感粒子）、断刀慢镜（time_scale+碎片+震屏）。
- **UI**：拟物仪表盘风（黄铜指针温度表、木牌订单卡），低频出现，主视角留给工位。

## 12. Godot 工程结构与关键技术点

```
res://
  sim/                  # 模拟层：纯 GDScript，无 Node 依赖，可 headless 单测
    blade.gd  heat.gd  forge.gd  quench.gd  temper.gd
    grind.gd  handle.gd  score.gd  ai_smith.gd  rng.gd
  data/
    steels/ orders/ rivals/ props/        # .tres 资源
  scenes/
    workshop/  arena/  stations/          # 工位场景
  mesh/blade_mesh_builder.gd              # BladeData → ArrayMesh
  fx/  ui/  audio/
  tests/                # GUT 单测（sim 层全覆盖，表现层不测）
  autoload/  (Game  Economy  Competition  AudioFx)
```

- **模拟节拍**：`_physics_process` 中累加器，固定 dt=0.1s 推 SimCore；渲染层 30 Hz 上限按 dirty 标记重建刀坯网格（16 段×八边形截面 ≈ 300 顶点，重建成本可忽略）；
- **BladeMeshBuilder**：每段生成八边形截面（脊部平、刃部楔），沿刃脊放样，`SurfaceTool` 提交；温度写入顶点色，shader 读顶点色查火色 LUT；断刀 = 按 hairline/断口段号截断生成两段网格；
- **确定性**：所有随机走 `sim/rng.gd`（种子可指定），比赛届数、AI 生成、淬裂掷签全部可复现——录屏出问题能重放调试；
- **单测优先**：热传导守恒、体积守恒、HRC 公式、六维边界，sim 层 100% 覆盖后再写表现层；
- **性能目标**：中端核显 1080p/60fps；粒子池化；场景 ≤200 万三角形。
