## 1. 游戏概述

### 1.1 一句话描述

你是一名从学徒起步的刀匠，在拟真的铁匠铺里亲手加热、锻打、淬火、开刃，打造真正的刀剑；用作品赢下随机组队的锻造大赛，赚取报酬升级装备，最终成为一代锻刀大师。

### 1.2 核心幻想（Core Fantasy）

- "这块钢在我手里一锤一锤变成了刀"——从一块冷硬的钢料到神兵利器的完整过程，全部亲手完成；
- "测试台上见真章"——锻造过程中埋下的每一分用心或偷懒，都会在武器测试的那一刻集中揭晓；
- "我的工坊越做越大"——从破旧小作坊到大师级锻造工场的成长。

### 1.3 核心卖点（USP）

1. **超写实的锻造工艺链**：真实钢材参数、真实温度区间、真实热处理原理，刀坯可逐段锤击塑形；
2. **隐藏属性驱动的悬念设计**：内应力、晶粒度、碳均匀度等不可见数值在锻造中积累，在测试环节爆发——这是同类游戏都没有的"见真章"时刻；
3. **竞技比赛结构**：随机组队淘汰赛提供持续挑战目标，区别于市面上全部是"温馨接单"框架的锻造游戏（市场空白）。

## 2. 核心循环

### 2.1 单局循环（一把刀，10~20 分钟）

```
接单/选命题 → 选材下料 → 炉中加热 → 抢温锻打 → 热处理(正火/淬火/回火)
→ 研磨开刃 → 装柄组装 → 成品测试/交付 → 结算报酬与评分
```

### 2.2 成长循环（数小时）

```
卖武器赚金币 → 购买更好的钢材/柄料 → 购置升级器械(炉/砧/动力锤/砂带机…)
→ 能承接更难订单 → 赚更多钱 → 升级工坊与陈列室
```

### 2.3 竞技循环（长线动力源）

```
日常锻造攒名声 → 报名大赛 → 随机组队4人淘汰赛 → 三轮对决+武器测试
→ 段位积分/赛季奖励 → 更高段位遇到更强对手 → 赛季刷新
```

## 3. 锻造模拟系统（核心玩法，最大篇幅）

### 3.1 总流程与工位

铁匠铺场景内设固定工位，玩家点击/移动切换，每工位一个专属交互界面与机位：

| # | 工位 | 操作内容 |
|---|---|---|
| 1 | 选料架/仓库 | 挑选钢材、柄料、配件 |
| 2 | 锻炉 | 加热钢料，管理温度 |
| 3 | 铁砧 | 锤击塑形（核心操作） |
| 4 | 热处理台 | 正火/退火/淬火/回火 |
| 5 | 砂带机/砂轮 | 研磨、开刃、抛光 |
| 6 | 钻台/装柄台 | 打孔、装配、缠柄 |
| 7 | 荡刀石 | 最终开锋 |
| 8 | 测试台/交付台 | 品质检测、出售或送赛 |

### 3.2 材料系统（拟真钢材库）

每种钢材有真实参数，直接参与计算：

| 钢材 | 含碳量 | 淬透性 | 韧性 | 耐磨 | 特点/难度 | 解锁 |
|---|---|---|---|---|---|---|
| 1045 | 0.45% | 低（需水淬） | 高 | 低 | 入门练习料，易锻 | 初始 |
| 1084 | 0.84% | 中（油淬） | 中 | 中 | 教科书级全能钢 | 初始 |
| 1095 | 0.95% | 中 | 中 | 高 | 高碳经典，淬裂风险高 | 名声 Lv2 |
| 5160 弹簧钢 | 0.60% | 高 | 极高 | 中 | 韧性之王，做长刃 | 名声 Lv3 |
| W2 | 1.0%+钒 | 中 | 中 | 高 | 可锻出羽毛纹 | 名声 Lv4 |
| 15N20+1095 | — | — | — | — | 大马士革叠焊组合 | 完成锻焊教学 |
| 玉钢(玉鋼) | 不均 | 低 | — | — | 传统日刀料，碳分布不均要自行调配 | 大赛冠军后 |

废料挑战材料（比赛与省钱玩法）：汽车弹簧、滚珠轴承、钢缆、旧锉刀、割草机刀片——参数随机、缺陷随机，便宜但看眼力。

柄料/配件：硬木、胡桃木、米卡塔、骨、鹿角、黄铜护手、缠绳、皮革，影响握持、配重与外观分。

### 3.3 加热系统（温度是第一资源）

- 刀坯沿刃脊分为 N 段（初版 16 段），每段独立存温度值，随时间自然冷却（端部冷却更快）；
- 炉型决定加热速度与温度上限：煤炉（便宜、控温难、有杂质渗碳）→ 燃气炉（稳定）→ 感应炉（精准、贵）；
- **温度-颜色对照拟真**（同时有数字温度显示，兼顾可玩性）：

| 温度 | 颜色 | 可做什么 |
|---|---|---|
| <550°C | 暗黑发蓝 | 只能看，锻不动 |
| 650°C | 暗红 | 回火区间；不可锻 |
| 750–900°C | 橙红→橙 | **锻造区间**：锤击有效 |
| 950–1100°C | 亮黄 | 精锻、锻焊区间 |
| >1200°C | 亮白 | **过热警告**：晶粒粗化，烧毁判废 |

- 温度落在区间外锤击：冷锻会积累内应力且几乎不变形；过热锻打直接损伤晶粒度——拟真且构成玩法约束。

### 3.4 锻打系统（操作核心）

**刀坯模型**：沿刃脊线排列的横截面控制点序列，每截面参数 = {宽, 厚, 左右偏移, 刃角}。整体网格由截面序列实时生成（SurfaceTool）。

**锤击交互**：
- 鼠标点击刀身任意位置 → 影响最近的截面（带衰减影响相邻段）；
- 锤击效果拟真**体积守恒**：压低厚度 → 宽度自动外扩；打侧面 → 控制偏移修正弯扭；
- 温度决定可锻性：锻造区间内变形效率 100%，越冷越低；
- 每一锤同时积累隐藏的**内应力**（与温差、锤重相关）。

**锤型选择**：

| 锤 | 效果 |
|---|---|
| 手锤（轻） | 精修截面，变形小、应力小 |
| 锻锤（中） | 标准拔长/展宽 |
| 大锤/动力锤（重） | 大变形、高效率，但应力大、易过打 |

**手感五件套**（M0 阶段就要调好）：命中火花粒子（GPUParticles3D）＋金属锤击声（随温度变音色：越热声越闷）＋相机微震＋锤子挥击动画＋截面实时形变反馈。

**目标轮廓**：订单/赛题给出目标截面曲线，玩家对照半透明轮廓叠影锻打，偏差计入几何误差评分。

### 3.5 热处理系统（拟真成败关键）

1. **正火**：锻后加热到 850°C 左右空冷 2~3 次 → 细化晶粒、消除部分内应力（做成可选操作，不做就带着粗晶粒进淬火）；
2. **退火**：慢冷软化，为研磨省力（影响研磨效率数值）；
3. **淬火**：
   - 临界温度判定：加热至失磁点（Ac3 附近，随钢种 760~830°C），可用磁铁道具测试（拟真细节）；
   - 介质三选：**油**（温和，几乎不裂，硬度略低）/ **水**（烈，硬度高，裂风险大）/ **盐水**（最烈，仅低碳钢救急用）；
   - 入液动画：蒸汽、油烟、滋响；淬裂概率 = f(钢材淬裂敏感度, 截面厚薄差, 介质烈度, 晶粒度)，淬裂当场炸裂报废（可读档，扣材料费）；
4. **回火**：炉温/时长设定（如 200°C×2h），硬度↔韧性天平，数值拟真（回火不足→测试崩刃；过度→软卷刃）。

### 3.6 研磨开刃

- 砂带机工位：按住推进刀坯，控制**研磨角度**（角度条 minigame）与力度，磨过头会过热退火（刀坯变色）；
- 砂目进阶：粗磨 80 → 240 → 400 → 800 → 镜面 2000，逐级目数影响表面分与锋利度上限；
- 开刃角：15° 锋利易卷 / 25° 均衡 / 35° 耐用但钝——由玩家按武器用途抉择。

### 3.7 装柄组装

- 龙骨类型：通龙骨（strongest）/ 棒式插入 / 尾铆固定，影响结构强度测试表现；
- 流程：钻孔 → 试配 → 环氧胶合 → 打销钉 → 修型 → 缠柄（绳/皮）；
- 配重影响操作测试的手感评分（重心位置拟真计算）。

### 3.8 隐藏属性系统（本作灵魂）

玩家全程看不到直接数值，只能凭经验与观察（火色、声音、手感）判断，测试环节集中揭晓：

| 隐藏属性 | 积累来源 | 爆发表现 |
|---|---|---|
| 内应力 | 低温锤击、淬火过激 | 强度测试弯折不回弹、崩刃 |
| 晶粒度 | 过热锻打、跳过正火 | 韧性骤降，冲击即断 |
| 碳均匀度 | 选料（玉钢/废料） | 局部软硬不均，刃口锯齿 |
| 几何误差 | 锻打偏差 | 评分扣分、配重失衡 |
| 淬硬均匀性 | 淬火手法、截面均匀 | 刃口分段卷刃 |
| 回火充分度 | 回火参数 | 崩刃/卷刃二选一 |

设计原则：**每个隐藏属性都有至少一个可感知的前兆信号**（声音发闷、颜色异常、磁铁吸附异常等），让高手能"读懂钢"，新手也能学习归因——失败永远知道为什么。

## 4. 竞技比赛系统（长线动力源）

### 4.1 大赛结构（原创包装，赛制思想可用）

- 每届大赛 **4 名选手随机组队**（玩家 + 3 名随机抽签的 AI 刀匠），三轮单败淘汰：
  1. **资格轮**：限定时间内（默认 60~90 磁性游戏分钟）按命题尺寸锻出刀刃并完成热处理，评委审工艺淘汰 1 人；
  2. **半决赛**：装柄成器 + 两项测试（强度+锋利），淘汰 1 人；
  3. **决赛**：数个游戏日内复刻一件历史名器（限定图鉴池），返场三测定冠。
- 赛事类型轮换：常规赛 / **限定材料赛**（只用废料）/ **历史复刻赛** / **命题创作赛**。

### 4.2 评委与仪式（全部原创，规避节目表达层）

- **沈铁山**——国家级锻造大师，主管工艺与结构，口头禅："钢不会说谎。"
- **顾文渊**——兵器考古学者，主管形制考据，负责讲解历史名器；
- **凌霜**——冷兵器格斗家，执行实战测试，通过判定词："**此刃，可堪一战！**"（原创口号，不用节目原句）；
- 淘汰仪式（原创文案）："你的作品将留在荣誉墙上，而你，止步于此。"
- 舞台美术自主设计：不采用节目式四炉一字排开+演播室配色，采用"武馆校场"风格布景。

### 4.3 AI 对手

- 对手池按段位生成，带"选手档案"（性格、擅长钢种、历史战绩）；
- 原型：稳健老匠（工艺分高、保守）、激进新人（创意分高、易翻车）、学院派（几何精准、测试弱）、野路子大师（废料专家）；
- AI 不模拟实时锻造，按难度+性格生成"合格品+随机缺陷"参与评比与测试演出。

### 4.4 武器测试环节（演出的高潮）

| 测试 | 内容 | 考验 |
|---|---|---|
| 强度测试 | 沈铁山猛砍硬物（钢桶/冰块/骨排）+ 压弯刀身看回弹 | 韧性、内应力、装柄强度 |
| 锋利测试 | 顾文渊连斩绳索/竹席/水瓶阵 | 开刃质量、硬度 |
| 实战测试 | 凌霜持刀对弹道假人模拟劈刺，原创判定词收尾 | 综合性能、配重 |

技术实现：目标物预切碎块+物理关节，命中按武器性能解除关节飞散；刀身断裂切换预制断刀模型+慢镜头特写。

### 4.5 段位与赛季

- 段位：学徒 → 匠人 → 精工 → 大师 → 宗师，积分升降；
- 赛季制：每赛季 8 周，刷新限定命题池与奖励（钢材图纸、限定柄料、陈列室装饰）；
- 每周轮换挑战（一题一排行，本地即可，后续可做异步云排行）。

## 5. 模拟经营系统（轻度）

### 5.1 经济循环

收入：订单交付（按规格完成度+品质计价）＞ 自由创作挂店出售（按品质+外观分定价）＞ 大赛奖金。
支出：材料（钢料/柄料/耗材）＞ 器械购置与升级 ＞ 工坊扩建 ＞ 报名费（大赛）。

### 5.2 器械升级树（展示成长的核心）

| 器械 | Lv1 | Lv2 | Lv3 |
|---|---|---|---|
| 锻炉 | 旧煤炉（慢、控温难） | 燃气炉（稳） | 感应炉（快准、带数控显示） |
| 铁砧 | 旧铁路砧 | 标准砧 | 大师级面砧（共振小） |
| 锤 | 手锤 | 电锤/空气锤 | 数控动力锤（可编程锤击） |
| 研磨 | 手持锉+砂轮 | 台式砂带机 | 变速水冷砂带机（防过热） |
| 热处理 | 油桶+温度计 | 控温烤箱 | 数字回火炉+介质槽 |

升级原则：高级器械降低拟真操作难度/提升效率，但**不替代手艺**——隐藏属性仍由玩家决策积累。

### 5.3 订单系统

- 顾客订单：带规格要求（刃长/重量/风格/钢材）与验收测试，完成度计价；
- 特殊 NPC 订单链：厨师（菜刀）、武馆（剑）、猎人（猎刀）、收藏家（复刻名器）——各自开启专属图纸。

### 5.4 陈列室与图鉴

- 工坊内设武器架/展示墙，出售前可选择"留样陈列"；
- 名器图鉴：收录历史名器（唐横刀、日本刀、维京剑、大马士革弯刀…），复刻成功点亮，附自写考据文案（**不用节目解说文案**）。

## 6. 技术方案（Godot 4.x）

| 模块 | 方案 |
|---|---|
| 刀坯网格 | 截面控制点序列 + SurfaceTool/ArrayMesh 实时重建，形变稳定且天然体积守恒 |
| 温度 | 每截面温度值 + 自定义 shader（自发光渐变：暗红→橙→黄→白），UI 辅助数字温度 |
| 物理 | Godot 4 内置 Jolt；测试环节预切碎块+关节方案，不做实时网格切割 |
| 粒子 | GPUParticles3D：火花、蒸汽、油烟、煤灰氛围 |
| 存档 | Resource 序列化武器全部参数（截面+隐藏属性），支持分享码（后续赛季异步对战用） |
| 性能目标 | 中端 PC 1080p/60fps；场景小而精（工坊内景+赛场内景） |
| 工具链 | 键鼠；后续评估手柄适配 |

## 7. 美术与音频方向（已修正：玩法拟真 ≠ 美术写实）

- **"超写实"指玩法模拟深度**（真实钢材、温度、热处理模型），美术采用轻量风格化方案：低多边形场景 + 简洁材质，拟真感由数值模拟、音效与特效承担，不追求画面照片级；
- 美术预算集中在四个特效点：**炉火、火花、蒸汽/油烟、断刀慢镜头**——小成本高回报；
- 摄影机：工位固定机位+微距特写（淬火、开刃、断刀慢镜头）；
- 音频：真实锤击/淬火/砂带采样，温度联动音色；环境声（炉火、风箱、蝉鸣/雨声）营造工坊氛围；
- 详细方案见《锻刀大师-系统详细设计》第 11 节。

## 8. 开发规划

| 里程碑 | 内容 | 验证目标 |
|---|---|---|
| **M0 技术原型（2~3 周）** | 截面刀坯+温度 shader+锤击变形+手感五件套，单一测试场景 | 锻打手感是否成立（最大风险前置验证） |

## 9. 合规要点（对应此前法律分析结论）

- 赛制骨架（三轮淘汰/测试裁决/限定材料）属于思想，可放心使用；
- 全部原创：游戏名、评委角色与口号、仪式文案、舞台美术、名器解说文案；
- 不在任何营销素材中提及/暗示与《锻造大赛》(Forged in Fire) 的关系；
